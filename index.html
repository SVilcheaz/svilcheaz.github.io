C++, ROS2, PX4, Gazebo, Jetson Orin Nano, Docker

An ongoing UAV autonomy project that separates the simulated aircraft from its companion computer: Gazebo and PX4 SITL run on a PC, while the ROS2 C++ mission controller runs on a Jetson Orin Nano over a DDS bridge. Phases 0 and 1 are complete, covering the distributed setup and autonomous takeoff, square-waypoint flight, and landing. The remaining roadmap adds perception, visual-inertial odometry, trajectory planning, sensor fusion, and vision-based precision landing.

Development roadmap

  1. Offboard flight control

    Complete

    Jetson-side C++ control of takeoff, waypoint flight, and landing in PX4/Gazebo, including a controller-loss recovery check.

  2. TensorRT perception

    Next up

    Run YOLOv8 on the Jetson against simulated camera feeds and measure inference latency.

  3. Visual-inertial odometry

    Planned

    Use Isaac ROS cuVSLAM with stereo camera and IMU data, comparing pose estimates with simulation ground truth.

  4. Trajectory planning & guidance

    Planned

    Generate smooth minimum-jerk trajectories in C++, add L1 path-following guidance, and develop local obstacle replanning.

  5. VIO / GPS sensor fusion

    Planned

    Fuse visual-inertial odometry and GPS with an extended Kalman filter, then evaluate behavior during simulated GPS dropouts.

  6. Vision-based precision landing

    Planned

    Integrate AprilTag detection and relative guidance into a complete simulated mission ending in a precision landing.

Inference Pipeline - Autonomous Car

An autonomous car that sees obstacles and follows people using onboard AI. A real-time C++ pipeline combines object detection and depth estimation on a Raspberry Pi 5 with a Hailo AI accelerator. Camera-based distance estimates guide steering and speed, while object tracking enables person-following. Voice commands add hands-free control, with an RC link available for manual override.
